# Guion breve de presentación

Duración orientativa: 60 a 90 segundos. Utilizar únicamente la demo ficticia y el
material preparado para el portafolio; revisar la grabación antes de compartirla.

1. **Presentación:** «Soy José Antonio Gallegos, AI & Backend Engineer. Desarrollo
   integraciones y herramientas para que las propuestas técnicas sean revisables».
2. **Problema:** «Al analizar cambios en un sistema existente, es importante relacionar
   los requisitos con evidencia y conservar las validaciones previas».
3. **Solución:** mostrar el caso de ingeniería asistida por IA y explicar la consulta
   de solo lectura, el diseño, la validación y la revisión humana.
4. **Demostración:** cambiar la referencia ficticia incorrecta por la correcta y
   mostrar el resultado del verificador.
5. **Alcance:** «Esta comprobación valida una referencia documental. La compilación
   y las pruebas funcionales se realizan en la implementación».
6. **Cierre:** mostrar el caso del agente híbrido y el repositorio público; invitar a
   revisar los proyectos y contactar desde el portafolio.
