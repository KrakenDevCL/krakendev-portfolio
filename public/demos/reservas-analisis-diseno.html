Análisis

Confirmación de reservas

Autor: José Antonio Gallegos Carvallo

Ejemplo creado desde cero para el portafolio. No reproduce datos, código ni documentos de un sistema empresarial.

1. Requisito funcional

Impedir la confirmación de una reserva si falta la fecha o si es anterior a la fecha mínima permitida. Conservar la validación de disponibilidad antes de guardar.

2. Comportamiento actual ilustrativo

La operación consulta disponibilidad y luego guarda la reserva. El fragmento disponible no incluye una comprobación de fecha.

101: Event 'Confirmar'
102:    ValidarDisponibilidad()
103:    GuardarReserva()
104: Endevent

3. Alcance y supuestos

La propuesta afecta únicamente a la confirmación. La fecha mínima es un dato de entrada configurado; se utiliza la misma referencia de calendario para comparar fechas. Se conserva el control de disponibilidad.

4. Escenarios de aceptación

EntradaResultado esperado
Fecha ausenteMostrar mensaje e impedir el guardado.
Fecha anterior al mínimoMostrar mensaje e impedir el guardado.
Fecha igual o posterior al mínimoContinuar con disponibilidad y guardado según las reglas existentes.
